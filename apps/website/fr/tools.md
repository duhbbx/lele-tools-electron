# Outils

16 outils organisés par catégorie. Chaque outil s'ouvre dans son propre onglet — l'état est entièrement indépendant.

## Encodage et formatage

| Outil | Description |
|-------|-------------|
| Formateur JSON | Formate, minifie et valide du JSON avec un éditeur Monaco |
| Formateur XML | Formate ou minifie du XML en conservant une structure claire et lisible |
| Formateur YAML | Formate du YAML et convertit entre YAML et JSON |
| Codec Base64 | Encode et décode en Base64 (compatible UTF-8) |
| Convertisseur de bases numériques | Convertit entre toute base (2–36) : binaire, hexadécimal et plus |

## Texte

| Chiffrement/déchiffrement de texte | Chiffrement AES-256-GCM par phrase secrète — entièrement local, sans fuite de données |

## Module CRM

Un CRM local intégré conçu pour les freelances et les petites équipes. Gérez clients, parties prenantes et projets dans une arborescence à trois niveaux ; chaque projet prend en charge des champs personnalisés comme les URLs de déploiement et les paramètres WeChat. Les entrées de paiement et les fichiers de contrats sont stockés avec les données du projet, avec nettoyage automatique lors de la suppression. Tout réside dans une base de données SQLite locale — pas de synchronisation cloud, contrôle total de la confidentialité.

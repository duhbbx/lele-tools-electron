# Feuille de route

## Terminé (v0.1)

- 15 outils purement front-end répartis en 5 catégories
- Assistant IA global (6 fournisseurs, conversation en streaming, historique local)
- Éditeur Monaco, thème clair/sombre, interface en anglais et chinois
- Persistance locale avec better-sqlite3

## En cours

- Première version officielle (installateurs pour les trois plateformes + CI GitHub Actions)

## Prévu (migration progressive depuis l'édition Qt)

- Lot d'outils système : hachage de fichiers, recherche de fichiers, éditeur Hosts, Ping, scanner de ports, informations système
- Lot d'outils réseau : client HTTP, WHOIS, lookup IP
- Outils avec état : bloc-notes, Todo (réutilisant la couche SQLite)
- Lot d'outils image : compression d'images, conversion de format, filigrane
- Mise à jour automatique (electron-updater)

> L'ordre et les priorités suivent les [GitHub Issues](https://github.com/duhbbx/lele-tools-electron/issues).

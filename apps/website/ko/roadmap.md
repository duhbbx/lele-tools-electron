# 로드맵

## 완료 (v0.1)

- 5개 카테고리에 걸친 15가지 순수 프론트엔드 도구
- 글로벌 AI 어시스턴트 (6가지 제공자, 스트리밍 대화, 로컬 기록)
- Monaco 에디터, 다크/라이트 테마, 영어·중국어 UI
- better-sqlite3를 이용한 로컬 영속성

## 진행 중

- 첫 번째 공식 릴리스 (세 플랫폼용 설치 패키지 + GitHub Actions CI)

## 계획 중 (Qt 버전에서 단계적 마이그레이션)

- 시스템 도구 배치: 파일 해시, 파일 검색, Hosts 편집기, Ping, 포트 스캐너, 시스템 정보
- 네트워크 도구 배치: HTTP 클라이언트, WHOIS, IP 조회
- 상태 저장 도구: 메모장, Todo (SQLite 레이어 재사용)
- 이미지 도구 배치: 이미지 압축, 포맷 변환, 워터마크
- 자동 업데이트 (electron-updater)

> 순서와 우선순위는 [GitHub Issues](https://github.com/duhbbx/lele-tools-electron/issues)를 따릅니다.

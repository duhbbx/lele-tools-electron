# 도구 목록

16가지 도구를 카테고리별로 정리했습니다. 각 도구는 독립된 탭에서 열리므로 상태가 서로 영향을 주지 않습니다.

## 인코딩 및 포매팅

| 도구 | 설명 |
|------|------|
| JSON 포매터 | Monaco 에디터로 JSON을 포맷·압축·검증 |
| XML 포매터 | XML을 포맷하거나 압축하여 구조를 깔끔하게 정리 |
| YAML 포매터 | YAML을 포맷하고 YAML과 JSON 간 변환 |
| Base64 코덱 | Base64 인코딩·디코딩 (UTF-8 지원) |
| 진수 변환기 | 임의의 진수(2~36) 간 변환: 2진수, 16진수 등 |

## 텍스트

| 도구 | 설명 |
|------|------|
| 문자 카운터 | 문자 수, 단어 수, CJK 문자 수 계산 |
| 정규식 테스터 | 실시간 하이라이트로 정규식 테스트 및 매칭 |
| 텍스트 암호화/복호화 | AES-256-GCM 패스프레이즈 암호화 — 완전 로컬 실행, 정보 유출 없음 |

## 생성기

| 도구 | 설명 |
|------|------|
| 비밀번호 생성기 | 길이와 문자 집합을 커스터마이징하여 안전한 랜덤 비밀번호 생성 |
| UUID 생성기 | UUID v4를 대량 생성하고 원클릭으로 복사 |
| QR 코드 생성기 | 텍스트나 URL을 QR 코드로 변환; 오류 수정 레벨과 크기 조정 가능; PNG 다운로드 지원 |

## 개발 협업

| 도구 | 설명 |
|------|------|
| Issue 이동기 | 다른 저장소의 이슈를 내 저장소로 일괄 이동 |

## 시간

| 도구 | 설명 |
|------|------|
| 타임스탬프 변환기 | Unix 타임스탬프와 사람이 읽을 수 있는 날짜 간 변환; 초·밀리초·마이크로초 지원 |
| Cron 표현식 파서 | Cron 표현식을 파싱하고 다음 실행 예정 시간 미리보기 |

| 도구 | 설명 |
|------|------|

## CRM 모듈

프리랜서와 소규모 팀을 위한 내장 로컬 CRM. 클라이언트, 이해관계자, 프로젝트를 3단계 트리 구조로 관리하며, 각 프로젝트는 배포 URL, WeChat 파라미터 등 커스텀 필드를 지원합니다. 결제 내역과 계약 파일은 프로젝트 데이터와 함께 저장되며, 삭제 시 자동으로 정리됩니다. 모든 데이터는 로컬 SQLite 데이터베이스에 저장 — 클라우드 동기화 없이 완전한 프라이버시 보호.

## Plataformas suportadas

| Plataforma | Formato |
|------------|---------|
| Windows | `.exe` (NSIS) / `.zip` |
| macOS | `.dmg` / `.zip` |
| Linux | `.deb` / `.rpm` / `.AppImage` |

## Compilar a partir do código-fonte

```bash
git clone https://github.com/duhbbx/lele-tools-electron.git
cd lele-tools-electron
pnpm install
pnpm dist   # resultado em apps/desktop/release/
```

Se o macOS disser que o app está "danificado", consulte as [Perguntas frequentes](/pt/docs/faq).

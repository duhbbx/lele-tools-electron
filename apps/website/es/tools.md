# Herramientas

16 herramientas organizadas por categoría. Cada herramienta se abre en su propia pestaña — el estado es completamente independiente.

## Codificación y formato

| Herramienta | Descripción |
|-------------|-------------|
| Formateador JSON | Formatea, minifica y valida JSON con un editor Monaco |
| Formateador XML | Formatea o minifica XML, manteniendo la estructura limpia y legible |
| Formateador YAML | Formatea YAML y convierte entre YAML y JSON |
| Códec Base64 | Codifica y decodifica Base64 (compatible con UTF-8) |
| Conversor de bases numéricas | Convierte entre cualquier base (2–36): binario, hexadecimal y más |

## Texto

| Herramienta | Descripción |
|-------------|-------------|
| Contador de caracteres | Cuenta caracteres, palabras y caracteres CJK |
| Tester de expresiones regulares | Prueba y hace coincidir expresiones regulares con resaltado en tiempo real |
| Cifrado/descifrado de texto | Cifrado AES-256-GCM con contraseña — se ejecuta completamente de forma local, sin filtraciones |

## Generadores

| Herramienta | Descripción |
|-------------|-------------|
| Generador de contraseñas | Genera contraseñas aleatorias seguras con longitud y juegos de caracteres personalizables |
| Generador de UUID | Genera valores UUID v4 en masa con copia en un clic |
| Generador de código QR | Convierte cualquier texto o URL en un código QR; nivel de corrección de errores y tamaño ajustables; descarga PNG |

## Módulo CRM

Un CRM local integrado diseñado para freelancers y equipos pequeños. Gestiona clientes, partes interesadas y proyectos en un árbol de tres niveles; cada proyecto admite campos personalizados como URLs de despliegue y parámetros de WeChat. Las entradas de pagos y los archivos de contratos se almacenan junto a los datos del proyecto, con limpieza automática al eliminar. Todo reside en una base de datos SQLite local — sin sincronización en la nube, control total de privacidad.

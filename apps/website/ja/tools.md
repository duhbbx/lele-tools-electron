# ツール一覧

16 個のツールをカテゴリ別に整理。各ツールは独立したタブで開くため、状態が互いに干渉しません。

## エンコードとフォーマット

| ツール | 説明 |
|--------|------|
| JSON フォーマッター | Monaco エディターで JSON をフォーマット・圧縮・検証 |
| XML フォーマッター | XML をフォーマットまたは圧縮し、構造を見やすく整理 |
| YAML フォーマッター | YAML をフォーマットし、YAML と JSON を相互変換 |
| Base64 コーデック | Base64 のエンコード・デコード（UTF-8 対応） |
| 進数コンバーター | 任意の基数（2〜36）間を変換：2進数、16進数など |

## テキスト

| ツール | 説明 |
|--------|------|
| 文字カウンター | 文字数、単語数、CJK 文字数を計測 |
| 正規表現テスター | リアルタイムハイライトで正規表現をテスト・マッチ |
| テキスト暗号化/復号 | AES-256-GCM によるパスフレーズ暗号化 — 完全ローカル動作、情報漏洩なし |

## ジェネレーター

| ツール | 説明 |
|--------|------|
| パスワードジェネレーター | 長さと文字種をカスタマイズして安全なランダムパスワードを生成 |
| UUID ジェネレーター | UUID v4 をまとめて生成し、ワンクリックでコピー |
| QR コードジェネレーター | テキストや URL を QR コードに変換。エラー訂正レベルとサイズを調整可能、PNG ダウンロード対応 |

## 開発コラボレーション

| ツール | 説明 |
|--------|------|
| Issue ムーバー | 他のリポジトリの Issue を自分のリポジトリへ一括移動 |

## 時刻

| ツール | 説明 |
|--------|------|
| タイムスタンプコンバーター | Unix タイムスタンプと人間が読める日時を相互変換。秒・ミリ秒・マイクロ秒に対応 |
| Cron 式パーサー | Cron 式を解析し、次回の実行予定時刻をプレビュー |

## その他

| ツール | 説明 |
|--------|------|
| カラーツール | HEX、RGB、HSL を相互変換し、リアルタイムでカラースウォッチをプレビュー |
| HTTP ステータスコード | 検索機能付きの HTTP ステータスコードクイックリファレンス表 |

## CRM モジュール

フリーランサーや小規模チーム向けに設計された内蔵ローカル CRM。クライアント、関係者、プロジェクトを 3 階層ツリーで管理。各プロジェクトはデプロイ URL や WeChat パラメーターなどのカスタムフィールドに対応。支払い記録と契約書ファイルはプロジェクトデータと一緒に保存され、削除時に自動クリーンアップ。すべてローカルの SQLite データベースに保存 — クラウド同期なし、プライバシーを完全管理。

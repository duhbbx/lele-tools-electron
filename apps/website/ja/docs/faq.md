# よくある質問

## インストールと起動

### macOS で「壊れている」または「開けません」と表示される

このアプリは Apple の公証を受けていません（公証には年間 $99 かかります — オープンソースプロジェクトには見合いません）。ターミナルで以下を一度実行して隔離フラグを解除してください：

```bash
xattr -dr com.apple.quarantine "/Applications/Lele Tools.app"
```

または、アプリを右クリック → 開く → 開くを選択してください。これは一度だけ必要な手順で、以降はダブルクリックで通常通り起動できます。

### Linux で起動エラーが発生する

`.deb` / `.rpm` パッケージは依存関係を宣言しているため、通常のパッケージマネージャーでインストールすれば自動的に取得されます。手動インストール後にライブラリが見つからないエラーが出た場合は、指定されたシステムパッケージをインストールしてください。AppImage は独自のランタイムを同梱しており、追加の依存関係は不要です。

## AI アシスタント

### AI に接続できない / リクエストが失敗する

以下の順に確認してください：

1. **API Key を確認**: 設定 → AI アシスタントに移動し、キーが完全であることを確認 — 余分なスペースや文字の欠落がないか確かめてください。
2. **BaseURL を確認**: カスタムエンドポイントを使用している場合、末尾のスラッシュがなく、アドレスに到達できることを確認してください。
3. **ネットワークプロキシ**: 一部の地域では OpenAI、Claude、Grok へのアクセスにプロキシが必要です。DeepSeek と Ollama（ローカル）はプロキシなしで動作します。
4. **接続テスト**: 設定ページの「接続テスト」ボタンを使って正確なエラーを確認してください。
5. **Ollama**: ローカルの Ollama サービスが起動しているか（デフォルト `http://localhost:11434`）、使いたいモデルをプルしているか（`ollama pull <モデル名>`）を確認してください。

## データとプライバシー

### データはどこに保存されますか？

すべてローカルの SQLite データベースに保存されます：

- **macOS**: `~/Library/Application Support/Lele Tools/lele.db`
- **Windows**: `%APPDATA%\Lele Tools\lele.db`
- **Linux**: `~/.config/Lele Tools/lele.db`

別のマシンに移行する際はこのファイルをバックアップしてください。

### アプリは何かをアップロードしますか？

**いいえ。** すべての機能はローカルで動作します。アプリはユーザーデータを一切収集しません。AI リクエストは Electron のメインプロセスから設定したプロバイダーに直接送信されます — 中間サーバーは一切ありません。

## このプロジェクトについて

### なぜ Electron に書き直して Qt 版を離れたのですか？

Qt 版（[lele-tools](https://github.com/duhbbx/lele-tools)）は 50 以上のツールに成長しましたが、数が増えるにつれ、C++/Qt のメンテナンス負担 — ビルド環境、クロスプラットフォームパッケージング、UI の一貫性維持 — も増え続けました。Electron + Vue 3 の Web スタックにより、UI 開発が速くなり、コンポーネントの再利用が簡単になり、AI 統合（ストリーミング SSE、マルチプロバイダー SDK）が完全に自然になりました。Electron 版はゼロから始まり、ツール数では徐々に Qt 版に追いついていきます。

### ツールの追加やバグ修正に貢献したい場合は？

1. [リポジトリ](https://github.com/duhbbx/lele-tools-electron) をフォーク
2. アーキテクチャの概要として [クイックスタート → 開発者向け：新しいツールを追加する](/ja/docs/getting-started#開発者向け新しいツールを追加する) を読む
3. Pull Request を開く

バグ報告や機能リクエストは [GitHub Issues](https://github.com/duhbbx/lele-tools-electron/issues) からどうぞ。

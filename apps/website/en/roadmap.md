# Roadmap

## Done (v0.1)

- 15 pure front-end tools across 5 categories
- Global AI assistant (6 providers, streaming conversation, local history)
- Monaco editor, dark/light theme, English/Chinese UI
- Local persistence with better-sqlite3

## In Progress

- First official release (installers for all three platforms + GitHub Actions CI)

## Planned (gradually migrating from the Qt edition)

- System tools batch: file hash, file search, Hosts editor, Ping, port scanner, system info
- Network tools batch: HTTP client, WHOIS, IP lookup
- Stateful tools: notepad, Todo (reusing the SQLite layer)
- Image tools batch: image compression, format conversion, watermark
- Auto-update (electron-updater)

> Order and priority follow [GitHub Issues](https://github.com/duhbbx/lele-tools-electron/issues).

# 功能一览

15 个工具，按分类列出。每个工具独立 Tab 打开，状态互不干扰。

## 编码 & 格式化

| 工具 | 说明 |
|------|------|
| JSON 格式化 | 格式化 / 压缩 / 校验 JSON，Monaco 编辑器 |
| XML 格式化 | 格式化 / 压缩 XML，保持结构整洁 |
| YAML 格式化 | YAML 格式化与 JSON 互转 |
| Base64 编解码 | Base64 编码与解码（UTF-8 安全） |
| 进制转换 | 任意进制（2–36）互转，支持二进制、十六进制等 |

## 文本

| 工具 | 说明 |
|------|------|
| 字符统计 | 统计字符数、单词数、中日韩字符 |
| 正则测试 | 正则表达式测试与匹配，实时高亮匹配结果 |
| 文本加解密 | AES-256-GCM 口令加解密，本地运行零泄露 |

## 生成器

| 工具 | 说明 |
|------|------|
| 随机密码 | 生成安全随机密码，可自定义长度与字符集 |
| UUID 生成 | 批量生成 UUID v4，一键复制 |
| 二维码生成 | 将文本或 URL 生成二维码，支持纠错等级与尺寸调整，可下载 PNG |

## 时间

| 工具 | 说明 |
|------|------|
| 时间戳转换 | 时间戳与日期互转，支持秒 / 毫秒 / 微秒 |
| Cron 表达式 | 解析 Cron 表达式，查看下次执行时间 |

## 其他

| 工具 | 说明 |
|------|------|
| 颜色工具 | HEX / RGB / HSL 颜色互转，带色块预览 |
| HTTP 状态码 | HTTP 状态码速查表，支持搜索 |

# 踩坑与要点

## monorepo 骨架

- `pnpm-workspace.yaml` 声明 `apps/*` 和 `packages/*`，根 `package.json` 只装 devDeps（biome、typescript、vitest）。
- 拷贝 db-tool 的 `vitest.config.ts` 需删头部公司版权注释；`tsconfig.base.json` 和 `biome.json` 无需改动。
- `pnpm.onlyBuiltDependencies` 需列 `electron`、`esbuild`、`better-sqlite3`，否则 pnpm v10 不执行其 postinstall 脚本。
- biome 安装后 pnpm 会提示 "Ignored build scripts"，运行 `pnpm approve-builds` 可解决（或在 `onlyBuiltDependencies` 里加 `@biomejs/biome`）。
